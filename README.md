# 🦆 嘎嘎特攻隊 (Gaga Survivor)

一款類似《噠噠特攻 / 嘎嘎特攻隊》（Survivor.io / 吸血鬼倖存者）風格的 2D 俯視角 Roguelike 割草動作網頁遊戲。從四位特工中挑一位出擊，選一張關卡，在怪物狂潮中走位突圍、佈署砲塔、升級裝備，合成震撼全場的毀滅級超武。單局 8 分鐘，擊敗終極首領即通關並解鎖下一關。

## 🚀 執行方式

因為使用 ES Modules，必須透過 HTTP 伺服器開啟（直接雙擊 `index.html` 會被瀏覽器的 CORS 政策擋下）：

```bash
python3 -m http.server 8791
```

然後開啟 <http://localhost:8791/index.html>。

## 🎮 操作方式

- **電腦操作**：
  - `W` `A` `S` `D` 或 `方向鍵`：特工移動
  - 滑鼠左鍵拖曳左下角 **虛擬搖桿** 同樣可進行精準走位
- **行動裝置 / 平板**：
  - 觸控滑動左下角 **虛擬搖桿** 即可全方位靈活操控
- **戰鬥**：
  - 所有武器均為 **全自動索敵攻擊**，專注於靈活走位、風箏怪物與拾取經驗寶石！
  - `B` 鍵或 HUD 上的 🔫 按鈕：花費金幣在原地 **佈署防禦砲塔**（行動端用按鈕）

## 🕵️ 四位特工

出擊前可自由選擇，每位有專屬外觀、特質與初始武器（選擇會被記住）。

| 特工 | 定位 | 專屬特質 | 初始武器 |
| :--- | :--- | :--- | :--- |
| **007 鴨鴨** 🦆 | 均衡新手推薦 / 單體點殺 | **特工風度**：移動時 +15% 暴擊率（暴擊 ×2 傷害），拾取範圍 +20% | 特工苦無 |
| **暴走蘿蔔** 🐰 | 極限跑速 / 範圍燃燒 | **兔子快跑**：基礎跑速 ×1.25；跑速每 +10% 全傷害 +5%；奔跑留下灼燒火痕 | 特工燃燒瓶 |
| **鋼鐵肥啾** 🐧 | 近身絞肉 / 站擼護盾 | **厚脂肪裝甲**：HP 130、受到傷害 ×0.8；被撞到觸發全場衝擊波 | 守護輪盤 |
| **脈衝喵喵** 🐱 | 冷卻縮減 / 全螢幕天罰 | **超頻過載**：擊殺菁英怪後 5 秒內所有武器冷卻減半 | 雷電矩陣 |

每位特工在出擊、升級、合成超武、瀕死、Boss 登場、通關與陣亡時都有專屬台詞。

## 🗼 塔防機制：防禦砲塔

用戰鬥中撿到的金幣就地佈署自動砲塔，替割草加上一層佈防思考。

- **費用**：首座 60 🪙，之後每多一座 +40（金幣不足時 HUD 按鈕會變灰）
- **性能**：射程 270、每 0.55 秒射擊一次、每發 26 傷害（約 47 DPS），Boss 優先鎖定
- **耐久**：900 HP，敵人會被砲塔擋住並持續啃食，撐不住就會爆炸
- **限制**：兩座砲塔至少相隔 70 距離，不能疊在同一點

## 🗺️ 四張關卡

單局 **8 分鐘**，Boss 在 2:00 / 5:00 出現，8:00 為終極首領 —— 擊敗即通關並解鎖下一關。波次組成、Boss 排程與畫面配色全部資料化在 [`js/levels.js`](js/levels.js)。

| 關卡 | 難度 | 敵人組成 | 終極首領 (HP) |
| :--- | :--- | :--- | :--- |
| 🌃 **淪陷商業街** | ★ | 喪屍為主，逐步混入蝙蝠與巨漢 | 巨神‧暴虐霸王龍 (42,000) |
| 🧪 **廢棄生化實驗室** | ★★ | 自爆毒蟲高比例，考驗遠程點殺 | 母體‧零號實驗體 (55,000) |
| ❄️ **極寒暴風雪基地** | ★★★ | 血厚巨漢＋高速蝙蝠，走位風箏 | 冰霜暴君‧雪帝 (68,000) |
| 🌋 **熔岩核心熔爐** | ★★★★ | 全精英混編，密度最高 | 毀滅特工‧暗影鴨 (88,000) |

Boss 血量依實測玩家 DPS 曲線（2 分約 200、5 分約 700、8 分約 1,200 DPS）反推每場 20~35 秒的理論擊殺時間，再乘上各關難度係數。雜兵血量 = `(1 + 時間/60 × 0.4) × 關卡 hpScale`。

## 💰 雙貨幣與局外養成

| 貨幣 | 來源 | 用途 |
| :--- | :--- | :--- |
| **金幣** 🪙 | 局內掉落（7% 機率） | **局內消耗**：佈署砲塔、升級選單的補給選項 |
| **基因密鑰 DNA** 🧬 | 每局結算 | **局外養成**：天賦樹、裝備工坊（開發中） |

DNA 公式：`(存活秒數/10 + 擊殺數/20 + 等級×2) × 關卡係數 × (通關 ×1.5)`。

進度存在單一 localStorage key `gaga_save`（[`js/save.js`](js/save.js)）：DNA 總量、已解鎖關卡、每關最佳紀錄與通關旗標、上次選的特工與關卡。舊版的兩個零散 key 會自動遷移。

## 🛠️ 技術架構

- **純原生 HTML5 + Canvas 2D + ES Modules**，零外部龐大依賴，隨開即玩。
- **Web Audio API 零依賴動態合成音效系統**：射擊、打擊、水晶叮咚、核爆、升級和弦號角、8-bit Synthwave 動態低音循環。
- **現代毛玻璃電競介面**：動態 HUD、平滑血條、升級卡牌三選一、戰後武器輸出數據統計。
- **Sprite 烘焙渲染管線**（`js/sprites.js`）：所有角色、怪物與砲塔的精緻筆刷（漸層打光、描邊、發光）在首次使用時烘焙成 8 格動畫 sprite（2 倍超取樣），遊戲中每幀只做 `drawImage`，畫質與效能兼顧。

```
js/levels.js          四張關卡的波次、Boss 排程與主題配色

js/sprites.js         sprite 烘焙 (角色/怪物/砲塔美術)

js/entities/          Player / Enemy / Projectile / DropItem / Turret
js/weapons/           WeaponManager (索敵、冷卻、暴擊、超武進化)

```
