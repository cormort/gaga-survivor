# 🦆 嘎嘎特攻隊 (Gaga Survivor)

一款類似《噠噠特攻 / 嘎嘎特攻隊》（Survivor.io / 吸血鬼倖存者）風格的 2D 俯視角 Roguelike 割草動作網頁遊戲。**兩種作戰模式**：純走位割草的「生存者」，與要守住基地核心的「守塔」。從四位特工中挑一位出擊，選一張關卡，在怪物狂潮中走位突圍、佈署砲塔、升級裝備，合成震撼全場的毀滅級超武。單局 8 分鐘，擊敗終極首領即通關並解鎖下一關。

**▶️ 線上遊玩：<https://cormort.github.io/gaga-survivor/>**（電腦與手機皆可）

---

## 🚀 本機執行

因為使用 ES Modules，必須透過 HTTP 伺服器開啟（直接雙擊 `index.html` 會被瀏覽器的 CORS 政策擋下）：

```bash
python3 -m http.server 8791
```

然後開啟 <http://localhost:8791/index.html>。

## 🎮 操作方式

- **電腦操作**：
  - `W` `A` `S` `D` 或 `方向鍵`：特工移動
  - `Space`（空白鍵）：**戰術閃避翻滾 (Dash)**（0.22 秒高速突進 + 無敵幀護盾，3.8 秒冷卻）
  - `B` 鍵或 HUD 🔫 按鈕：花費金幣在原地 **佈署防禦砲塔**
  - `T` 鍵或動作欄 ⚙️ 按鈕：靠近標準砲塔時消耗 50 🪙 **進化砲塔模組**
  - 暫停後出現 🚪 **放棄任務**：以失敗結算後回主選單（該局金幣與 DNA 照常入帳）
  - 滑鼠左鍵拖曳左下角 **虛擬搖桿** 同樣可進行精準走位
- **行動裝置 / 平板**：
  - **點畫面任一處，搖桿就跳到指尖**（動態搖桿），也可直接拖曳左下角的固定搖桿
  - 右下角整合 **動作欄**（⚡ 翻滾、🔫 砲塔佈署、⚙️ 模組進化），點擊即可順暢施放
  - 已適配瀏海安全區、動態視窗高度（網址列收合不露白邊）、直向與橫向版面，並擋掉下拉刷新與雙擊縮放
- **戰鬥與戰術**：
  - 所有武器均為 **全自動索敵攻擊**，玩家只負責走位、翻滾躲彈幕與引爆場景物件
  - **連擊狂潮**：擊殺累加 Combo（3.6 秒無擊殺歸零），第 30 連擊與之後每 25 連擊觸發 7.5 秒狂潮，全武器攻速 +35%
  - **打擊頓挫**：擊殺 Boss 停格 80ms、精英怪 35ms，強化重擊手感

## 🎯 兩種作戰模式

出擊前先選模式。模式只描述規則差異，全部資料化在 [`js/modes.js`](js/modes.js) 的 `MODES`，新增模式不用動引擎。

| | 🏃 **生存者** | 🗼 **守塔** |
| :--- | :--- | :--- |
| 核心規則 | 怪物只追著你跑，撐過 8 分鐘 | 中央基地核心被圍攻，**破了就結束** |
| 砲塔／傭兵 | ❌ 完全沒有 | ✅ 主要火力來源 |
| 雜兵索敵目標 | 玩家 | 基地核心（Boss 仍鎖玩家）|
| 玩家武器輸出 | ×1 | **×0.6** |
| 金幣收入 | ×1 | **×2.2** |
| 砲塔費用 | — | **×0.6**（首座 36 🪙）|
| 失敗條件 | 特工陣亡 | 特工陣亡 **或** 核心被摧毀 |

**基地核心**（[`js/entities/Core.js`](js/entities/Core.js)）：14,000 HP，放在世界原點，玩家開場站在核心下方。雜兵貼上來就啃，HP 歸零即任務失敗；血量低於 30% 時 HUD 血條轉紅並呼吸警示。

> **關於同時攻擊數上限**：核心的啃食傷害只由最外圈的 16 隻結算（`main.js` 的 `CORE_MAX_ATTACKERS`），推擠阻擋則對所有貼上來的怪生效。這不是偷懶——實測若讓傷害隨怪數無上限累加，會有 249 隻同時貼著核心啃、瞬間衝到 2,972 DPS，核心開多少血都是幾十秒被秒。加上上限後進入核心的傷害穩定在 ~195 DPS，14,000 HP ≈ 完全不防守時 90 秒破核。

**實測難度曲線**（同一關、同一特工）：完全不防守 91 秒破核；繞著核心走位並有錢就佈防（最後 12 座砲塔、6 名傭兵、973 擊殺）撐到 7:05。要通關得比這個更會擺塔。難度要調就改 `modes.js` 的 `core.hp` 一個數字。

**進度分離**：兩種模式的**關卡最佳紀錄與解鎖進度各記一份**，但**養成完全共用** —— DNA、天賦、裝備倉庫、已解鎖特工跨模式共享。舊存檔（v3）自動遷移：原本的紀錄歸入生存者，已解鎖關卡兩個模式各複製一份，老玩家不會被鎖回第一關。

每日挑戰固定跑生存者模式（賣點是「同一天所有人條件一致」，跟著當前模式跑就破功了）。

**Boss 技能**：除了內建衝鋒，各 Boss 另帶 `summon`（召喚小怪）、`nova`（範圍震波）、`barrage`（扇形彈幕）、`vortex`（引力漩渦）與 `ground`（地面定點爆破雷區）；施放前 1.5 秒有刻紋前搖警示（內縮實圈＋旋轉虛線外環＋輻條角標，越接近施放越亮），大招出手瞬間畫面邊緣泛紅一閃。

**Boss 造型**：四關各有一套主題外觀（由 `levels.js` 的 Boss `skin` 帶入）——街頭巨屍（工程鋼帽／輪胎肩甲／甩鏈鎚球）、生化聚合體（黏液觸手／多珠眼）、冰霜機甲（八角裝甲／冰晶肩刺／軍用目鏡）與熔岩暴君（熔岩龜甲／邪目鴨噱／犄角）；**最終首領**自動換上更大號加戴王冠／觸手冠／冰披風／特工高帽的專屬造型，衝鋒時各自切換動作圖。一般雜兵則會隨機套一種開場就烘焙好的**尺寸變體**（0.95× / 1× / 1.07×），成群時彼此交錯，不再是一排複製貼上。

**精英詞綴**：普通怪有機率帶詞綴（`min(10%, 3.5% + 秒數/9000)`，8 分鐘一般關實際封頂約 8.8%，只有無盡關會摸到 10%），四種各有專屬顏色呼吸光環 —— 疾風（速度 ×1.5）、裝甲（HP ×1.6、減傷 50%）、巨獸（HP ×2.5、體型 ×1.45）、劇毒（全面小幅強化）。精英怪掉落保底紫水晶。

**里程碑獎勵**：每 100 擊殺輪播一次〔磁力空投／獎勵金幣／戰地醫療／震撼彈〕，每 2 分鐘一次總部後勤補給。

每關有專屬的**場景裝飾散佈**（商業街的報廢汽車／垃圾桶／霓虹招牌、實驗室的培養槽／管線／警示標、雪地的冰柱／雪堆／雷達碟、熔爐的岩漿裂隙／鋼板／齒輪），由世界座標的雜湊決定位置，不佔記憶體也不會隨相機飄移。

每關另有程序化**地面材質層**與全域調光：材質細節（焦裂柏油＋縫裂＋人孔蓋／金屬刷紋＋鉚釘／霜雪顆粒＋輝光／玄武岩碎屑＋透光餘燼／虛空星塵＋星點，依 `theme.ground.material`）與世界錨定的專屬筆觸（霓虹微光裂縫／金屬板接縫與腐蝕斑／冰晶簇霜紋／熔岩地殼裂縫／符文刻痕，依 `motif`），會一起烘進一片**無接縫紋理磚**——世界座標雜湊決定內容，開場每關只烘焙一次並快取，之後每一幀只做 `drawImage` 平鋪，不再逐格向量繪製。再疊上關卡專屬的極淡色調漸層（只染場景、不染角色）與分級暗角。地面火海（燃燒瓶／燃油煉獄）是**地面油漬 + 隨半徑調整數量的擺動火舌 + 根部白熱帶 + 竄升火星**四層疊出來的，關鍵是根部最亮、火舌歪斜、舌尖透明——反過來畫（對稱錐體、亮舌尖）會變成水晶柱。戰鬥中地板會留下數秒內淡出的**血漬**（顏色隨敵種）與**爆炸焦痕**——全部在 `js/levels.js` 的 `theme.ground / grade / vignette` 資料化調校，改數值不動引擎。

Boss 血量依實測玩家 DPS 曲線（2 分約 200、5 分約 700、8 分約 1,200 DPS）反推每場 20~35 秒的理論擊殺時間，再乘上各關難度係數。

雜兵的成長係數集中在 [`js/levels.js`](js/levels.js) 的 `enemyScale(gameTime, level)`，Spawner、胞囊孵化、死亡裂解共用同一份公式：

- **血量** = `(1 + 時間/60 × 0.4) × 關卡 hpScale`（無盡關另疊 `1 + 時間/300`），8 分鐘熔爐關為 ×8.4
- **傷害** = `min(1.8, 1 + 時間/60 × 0.1)`，8 分鐘封頂 1.8 倍

傷害成長是刻意加的：原本只有血量會漲，後期敵人只是變厚而完全不變兇，體感從「威脅」淪為「磨」。以熔爐關的攻城巨像為例，單次撞擊從 24 漲到 43，配合 0.5 秒無敵時間，最壞情況進傷由 48 HP/s 提高到 86 HP/s。

**終極首領的實際門檻**：30 秒內擊殺分別需要 1,400 / 1,833 / 2,267 / 2,933 DPS。一局約可升到 16~17 級（8 分鐘約 1,400 隻雜兵、平均 1.5 exp），扣掉養一把超武要花的 10 張升級卡，實戰輸出大約是「一把超武 + 三把半殘武器」，因此**第四關實質上需要靠局外裝備補足**。

武器池八把（苦無／守護輪盤／火箭／燃燒瓶／雷電／足球／**相位飛刃**／**重力環鋸**），後兩把為開路與護身原型的新擴充；重力環鋸刻意以貼身小半徑高速軌道與守護輪盤的寬軌道區隔。

**環繞型武器的傷害節奏**由 `WeaponManager` 的 `ORBIT_REHIT`（0.4 秒）決定：同一片刀刃每 0.4 秒才能再打到同一隻敵人。超武的環是永久旋轉（`baseCooldown: 0`），只要規格沒變就原地保留、不重建——早期版本每 0.08 秒重建整組環，等於不斷清空命中清單，造成每目標 400+ DPS 的失控輸出。彈跳球同理走 `SOCCER_REHIT`（0.5 秒），不然一顆球對同一隻怪一輩子只能打一次，24 次彈跳形同白給。

八把超武的單體 DPS 目前落在 **150~409**（落差 2.7 倍），且**每一把都強於自己滿級的基礎型態**。

## 🔮 蓄能彈：投射武器的元素屬性

投射武器每打出固定發數，**下一發自動變成蓄能彈**，附帶元素效果（逐發計數，不是逐輪；三連發的苦無三發各自計數）。彈體會帶對應顏色的光暈，敵人身上也有對應的狀態特效。數值集中在 [`js/config.js`](js/config.js) 的 `CHARGE`，武器只要加一行 `charge: { every, effect }` 就能掛載。

| 屬性 | 效果 | 定位 |
| :--- | :--- | :--- |
| 🔥 **燃燒** | 18 DPS 持續 3 秒，重複命中**刷新時間不疊層** | 高爆發短時間 |
| ⚡ **電弧** | 命中後跳躍 3 次、範圍 190，每跳衰減至 65%，不重複打同一隻 | 清群 |
| ❄️ **冰凍** | 雜兵**完全定住** 1.1 秒（且無法開火／孵化）；**Boss 免疫硬控**，改吃 2.4 秒減速 | 控場 |
| ☠️ **中毒** | 7 DPS 持續 5 秒，**可疊 5 層**（滿層 35 DPS） | 打高血量目標 |

| 武器 | 間隔 | 屬性 |
| :--- | :--- | :--- |
| 特工苦無 / 幽靈手裏劍 | 每 5 / 6 發 | 🔥 燃燒 |
| 相位飛刃 / 相位風暴 | 每 4 / 8 發 | ⚡ 電弧 |

## 🛠️ 技術架構

- **純原生 HTML5 + Canvas 2D + ES Modules**，零外部龐大依賴，隨開即玩。
- **Web Audio API 零依賴動態合成音效系統**：射擊、打擊、水晶叮咚、核爆、升級和弦號角；BGM 為五關主題 × 四層合成引擎（鼓組／Bass／Pad／Lead，`js/audio.js` 全資料驅動），聽感與音量全走同一主增益控管。
- **右下角小地圖**：以玩家為中心的 1300 單位局部視野，標示敵人、Boss（超出範圍時貼邊當方位指示）、砲塔、稀有掉落物與地圖邊界。
- **現代毛玻璃電競介面**：動態 HUD、平滑血條、升級卡牌三選一、戰後武器輸出數據統計。
- **Soulstone Survivors 風格視覺管線**：程序化地面**材質烘焙**（世界座標雜湊 → 每關預烘一片無接縫紋理磚，之後純 `drawImage`）、全域色調調光與分級暗角、地面殘跡（血漬／焦痕）、AOE 刻紋圓陣警示與 Boss 三層前搖、大招紅閃——色板集中在 `js/config.js` 的 `FX` 與 `js/levels.js` 的 theme，調色不動引擎。
- **Sprite 烘焙渲染管線**（`js/sprites.js`）：所有角色、怪物、砲塔與經驗水晶的精緻筆刷（漸層打光、描邊、發光）在首次使用時烘焙成 sprite（2 倍超取樣；角色 8 格動畫、場景物與水晶單格），遊戲中每幀只做 `drawImage`，畫質與效能兼顧。敵人支援**外觀變體**：雜兵按開場抽到的 `:v0/v1/v2` 別名烘焙出 0.95×/1×/1.07× 尺寸、Boss 依關卡 `skin` 烘焙一般／衝鋒／最終三種造型——都只要新增鍵名即可，每幀成本不增加。經驗水晶是場上數量最多的物件（實測 7:50 有 126 顆、佔掉落物 91%），改走烘焙後外圈光暈直接烘進圖裡，省下每顆每幀一次 `shadowBlur` —— 最壞情況（畫面內 200 隻怪 + 600 顆粒子 + 跳字滿載）每幀 `shadowBlur` 由 137 次降到 9 次、canvas 呼叫由 5,871 降到 4,082。
