# 🦆 嘎嘎特攻隊 (Gaga Survivor)

一款類似《噠噠特攻 / 嘎嘎特攻隊》（Survivor.io / 吸血鬼倖存者）風格的 2D 俯視角 Roguelike 割草動作網頁遊戲。從四位特工中挑一位出擊，選一張關卡，在怪物狂潮中走位突圍、佈署砲塔、升級裝備，合成震撼全場的毀滅級超武。單局 8 分鐘，擊敗終極首領即通關並解鎖下一關。

**▶️ 線上遊玩：<https://cormort.github.io/gaga-survivor/>**（電腦與手機皆可）

---

## 🚀 本機執行

因為使用 ES Modules，必須透過 HTTP 伺服器開啟（直接雙擊 `index.html` 會被瀏覽器的 CORS 政策擋下）：

```bash
python3 -m http.server 8791
```

然後開啟 <http://localhost:8791/index.html>。

## 🎮 操作方式

- **電腦操作**：
  - `W` `A` `S` `D` 或 `方向鍵`：特工移動
  - `Space`（空白鍵）：**戰術閃避翻滾 (Dash)**（0.22 秒高速突進 + 無敵幀護盾，3.8 秒冷卻）
  - `B` 鍵或 HUD 🔫 按鈕：花費金幣在原地 **佈署防禦砲塔**
  - `T` 鍵或動作欄 ⚙️ 按鈕：靠近標準砲塔時消耗 50 🪙 **進化砲塔模組**
  - 滑鼠左鍵拖曳左下角 **虛擬搖桿** 同樣可進行精準走位
- **行動裝置 / 平板**：
  - **點畫面任一處，搖桿就跳到指尖**（動態搖桿），也可直接拖曳左下角的固定搖桿
  - 右下角整合 **動作欄**（⚡ 翻滾、🔫 砲塔佈署、⚙️ 模組進化），點擊即可順暢施放
  - 已適配瀏海安全區、動態視窗高度（網址列收合不露白邊）、直向與橫向版面，並擋掉下拉刷新與雙擊縮放
- **戰鬥與戰術**：
  - 所有武器均為 **全自動索敵攻擊**，玩家只負責走位、翻滾躲彈幕與引爆場景物件
  - **連擊狂潮**：擊殺累加 Combo（3.6 秒無擊殺歸零），第 30 連擊與之後每 25 連擊觸發 7.5 秒狂潮，全武器攻速 +35%
  - **打擊頓挫**：擊殺 Boss 停格 80ms、精英怪 35ms，強化重擊手感

## 💰 雙貨幣與局外養成

| 貨幣 | 來源 | 用途 |
| :--- | :--- | :--- |
| **金幣** 🪙 | 局內掉落（7% 機率）、里程碑獎勵 | **局內消耗**：佈署砲塔、升級三選一的 60 🪙 刷新、急救包 |
| **基因密鑰 DNA** 🧬 | 每局結算 | **局外永久養成**：基因強化天賦、解鎖新特工 |
| **裝備** 🎒 | 精英怪與 Boss 掉落 | **局外永久養成**：三個部位、隨機詞條 |

DNA 公式：`(存活秒數/10 + 擊殺數/20 + 等級×2) × 關卡係數 × (通關 ×1.5)`。

### 🎒 打寶與裝備（MVP）

精英怪與 Boss 會掉落帶隨機詞條的裝備，撿到當下就直接進倉庫（陣亡也不會掉），在主選單穿上即永久生效。

| 稀有度 | 詞條數 | 一般掉落 | Boss | 終極首領 |
| :--- | :--- | :--- | :--- | :--- |
| 🔵 精良 | 1 | 68% | 45% | 30% |
| 🟣 史詩 | 2 | 27% | 40% | 48% |
| 🟡 傳奇 | 3 | 5% | 15% | 22% |

- **掉落來源**：精英詞綴怪 22%、階段 Boss 100%、終極首領 100%（大幅偏向高稀有度）
- **三個部位**：🕶️ 特工墨鏡（偏火力／冷卻）、🧥 特工風衣（偏生命／磁力）、👟 特工皮鞋（偏疾速／財運）
- **六種詞條**：火力（傷害 %）、堅韌（生命上限）、疾速（移速 %）、磁力（拾取範圍 %）、冷卻（CD 縮減 %）、財運（金幣 %）
- **物品等級**：關卡難度 + 存活時間決定，數值最高約 2 倍
- **倉庫上限 30 格**；裝備／脫下／分解都在主選單的「🎒 裝備倉庫」
- **分解換 DNA**：精良 5~8、史詩 14~22、傳奇 32~51（依物品等級）。已穿在身上的要先脫下才能分解，另有「分解全部精良／史詩」的批次按鈕
- **倉庫滿了不會白撿**：戰鬥中撿到裝備若倉庫已滿，會就地分解成 DNA 並提示

三件滿詞條傳奇的上限約：傷害 +30%、生命 +109、移速 +12%、磁力 +25%、冷卻 -10%、金幣 +59%。實測終局 DPS 從 2,600 提升到 3,161（再加滿級火力核心天賦為 3,726），首關終極首領的理論擊殺時間 16.2 秒 → 11.3 秒。

## 🛠️ 技術架構

- **純原生 HTML5 + Canvas 2D + ES Modules**，零外部龐大依賴，隨開即玩。
- **Web Audio API 零依賴動態合成音效系統**：射擊、打擊、水晶叮咚、核爆、升級和弦號角、8-bit Synthwave 動態低音循環。
- **右下角小地圖**：以玩家為中心的 1300 單位局部視野，標示敵人、Boss（超出範圍時貼邊當方位指示）、砲塔、稀有掉落物與地圖邊界。
- **現代毛玻璃電競介面**：動態 HUD、平滑血條、升級卡牌三選一、戰後武器輸出數據統計。
- **Sprite 烘焙渲染管線**（`js/sprites.js`）：所有角色、怪物與砲塔的精緻筆刷（漸層打光、描邊、發光）在首次使用時烘焙成 8 格動畫 sprite（2 倍超取樣），遊戲中每幀只做 `drawImage`，畫質與效能兼顧。

## 🚧 後續開發規劃

每項附上「動哪些檔、接哪些現成鉤子、做完怎麼算過」，可直接當工單接手。共通原則見 `CLAUDE.md`：資料驅動優先（能寫在 `config.js` / `levels.js` 的就不要寫死在邏輯裡）、最小改動、不重構沒壞的東西。

### 1. 更多地形互動

目前是定點式的毒霧／地雷／噴發（`levels.mech` + `main.js` 的 `updateHazards()`）。

- **要動**：`js/levels.js` 的 `mech` 設定、`js/main.js` 的 `updateHazards()` / `spawnHazard()` / `explodeHazard()`。
- **建議項目**：冰面滑行慣性（雪地關給玩家加速度衰減而非瞬停）、熔岩漫溢的安全高台（反向機制：只有站在特定區域才安全）、縮圈結界（隨時間縮小的安全圈，圈外持續扣血）。
- **注意**：`mech` 目前是單一物件，要多種同時存在得改成陣列 —— 這是唯一需要動到既有資料結構的地方，改的時候四關的設定要一起更新。
- **驗收**：新機制純靠 `levels.js` 的資料開關即可掛到任一關，關掉後舊行為完全不變。

### 2. 裝備進階玩法

分解、重鑄已上線（`js/items.js` + `js/save.js`）。

- **要動**：`js/items.js`（套裝判定與傳奇特效表）、`js/save.js`（合成／賭裝的存檔操作，比照現有的 `salvageItem` / `reforgeItem` / `equipItem`）、`js/systems/UI.js`（倉庫介面新增按鈕）、`js/weapons/WeaponManager.js`（會改變武器行為的傳奇特效才需要動）。
- **建議項目**：同稀有度三合一升階、套裝效果（三件同系列額外加成）、改變武器行為的傳奇特效（例如「苦無改為穿透全場」）。
- **現成鉤子**：`gearBonuses(stash, equipped)` 是所有裝備加成的唯一出口，新加成從這裡回傳即可；`AFFIXES` / `RARITIES` 都是資料表。
- **驗收**：新玩法不影響既有存檔（`save.js` 有 `ensureDefaults()`，新欄位要在那裡補預設值）。

### 3. 局內回收風險（Halls of Torment 式「裝備井」）

撤離井已經帶來「活著撤退才有獎勵」的雛形，但裝備目前撿到就直接入袋、陣亡也不會掉。

- **要動**：`js/main.js` 的 `spawnDropItem()` 與 `handleGameOver()`、`js/save.js` 的 `addItem()`、`js/systems/UI.js`（HUD 顯示本局待帶回的裝備）。
- **設計**：本局撿到的裝備先進「暫存區」，通關或從撤離井撤退才寫入倉庫，陣亡則損失（或只保留一定比例）。
- **驗收**：陣亡、通關、撤離三條路徑的結算差異清楚呈現在戰後畫面上。

### 4. 主邏輯模組化解耦

- `js/main.js` 已逼近 2,000 行，狀態機、碰撞、地形機制、局內事件、結算全擠在一起。
- 建議切分順序：`updateHazards` 系列 → `js/systems/Hazards.js`；撤離井／可引爆物件／幸運箱 → `js/systems/Events.js`（`js/systems/` 就是放這種東西的地方）。
- **驗收**：搬完後遊戲行為零變化，`main.js` 只留主迴圈與狀態機。

### 已知技術債

- 專案沒有測試框架，驗證方式是寫拋棄式 Node 腳本直接 import 模組跑 assert（`config.js` 會讀 `window`，記得先 `globalThis.window = { innerWidth: 1280, innerHeight: 720 }` 再動態 import）。
- 數值散在 `config.js`、`levels.js`、`Turret.js`、`items.js` 四處；新增系統時優先放進既有的表，不要在邏輯裡硬寫魔術數字。
